Privacy Policy for Verification Post Filter for X

Last updated: August 6, 2026

Verification Post Filter for X examines the X page currently open in your browser solely to identify verified-account badges and the public username shown with each post. This processing occurs locally in your browser.

The extension does not collect, retain, sell, or transmit page content, browsing history, authentication information, personal communications, or usernames encountered while browsing to the developer or any third party.

Information stored

  • Whether filtering is enabled.
  • Which verification badge categories you choose to filter.
  • Public X usernames that you explicitly add to the manual whitelist.
  • Public X usernames collected when you explicitly run the Following import.

On Chromium browsers, the enabled setting, badge-category choices, and manual whitelist use synchronized extension storage; imported Following accounts use local extension storage. On Firefox, all extension settings and imported accounts remain in local extension storage. The developer cannot access either storage area.

Following import

The Following import is read-only. It reads public usernames displayed in the central list as you scroll your Following page. It never follows, unfollows, posts, likes, sends messages, or changes your public X account.

Sharing and external services

The extension contains no analytics, advertising, tracking, remote code, or developer-operated network service. No extension data is shared with the developer or third parties. Access is limited to x.com and twitter.com to provide the filtering function.

Your choices

You can clear imported accounts and manual whitelist entries in the extension popup, or remove all extension data by uninstalling the extension.

Contact

For support or privacy questions, use the support contact provided on the extension's Chrome Web Store listing.
